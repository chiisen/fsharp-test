# 🚀 fsharp-test

VSCode F# 的測試專案 ✨

## 🛠️ 如何執行專案

請依照以下步驟在終端機執行此專案：

1. **進入專案目錄**：
   ```powershell
   cd ConsoleApp1
   ```

2. **執行程式**：
   ```powershell
   dotnet run
   ```

或者直接從根目錄執行：
```powershell
dotnet run --project ConsoleApp1/ConsoleApp1.fsproj
```

> [!NOTE]
> 本專案目前開發環境使用 **.NET 10.0**。請確保您的電腦已安裝對應版本的 SDK。

## 📝 專案內容
這是一個簡單的 F# 控制台應用程式，會計算並印出 1 到 10 的平方數。
